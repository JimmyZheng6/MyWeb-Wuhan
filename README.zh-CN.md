## 📖 项目简介

**MyWeb-Wuhan（江城武汉）** 是一个以武汉城市文化为主题的静态网页项目。

本项目采用 **HTML5** 与 **CSS3** 开发，作为华中科技大学 **《Computer Skills Practice for Freshman》** 课程的期末网页设计项目完成，最终课程成绩 **95/100**。

网站从四个主题展示我的家乡武汉：

- 🍜 美食记忆
- 🌉 江城风光
- 📖 我的时光
- 🏮 汉味文化

---

## ✨ 项目特色

- 多页面静态网站
- 响应式布局
- 固定导航栏
- 首页卡片式导航
- CSS 悬停动画
- 简洁统一的页面设计
